# 📚 Online Bookstore Data Analysis (SQL)

## 📌 Project Overview

This project focuses on analyzing an online bookstore's data using **PostgreSQL**. The objective is to extract meaningful insights from books, customers, and orders using SQL queries.

## 🎯 Project Objectives

* Analyze book inventory and sales.
* Identify customer purchasing patterns.
* Calculate total revenue from orders.
* Find popular books, genres, and authors.
* Analyze customer spending behavior.

## 🛠️ Tools & Technologies

* **Database:** PostgreSQL
* **SQL Tool:** pgAdmin
* **Language:** SQL

## 🗂️ Database Structure

The project contains three main tables:

* **Books:** Book ID, Title, Author, Genre, Published Year, Price, Stock
* **Customers:** Customer ID, Name, Email, Phone, City, Country
* **Orders:** Order ID, Customer ID, Book ID, Order Date, Quantity, Total Amount

## 📊 Key Analysis

### Basic SQL Analysis

* Retrieve books by genre.
* Filter books by publication year.
* Find customers by country.
* Calculate total available stock.
* Identify the most expensive and lowest-stock books.
* Calculate total revenue.

### Advanced SQL Analysis

* Calculate books sold by genre and author.
* Find customers who placed at least two orders.
* Identify the most frequently ordered book.
* Find the top three most expensive Fantasy books.
* Analyze customer spending and identify the highest-spending customer.
* Calculate remaining stock after fulfilling orders.

## 💡 SQL Concepts Used

* SELECT, WHERE, ORDER BY
* GROUP BY, HAVING
* Aggregate Functions (SUM, AVG, COUNT)
* JOIN
* DISTINCT
* LIMIT
* COALESCE
